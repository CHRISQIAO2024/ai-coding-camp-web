# 拾伍词：30天雅思6.5词汇训练

面向英语基础中等的国际学校高中生。每天学习15个适中难度的雅思核心词，包含到期复习、词义辨认、听音拼写、语境搭配、每日小测和30天评估报告。

## 使用方式

直接打开 `index.html` 即可使用。学习数据保存在当前浏览器中，不会上传到服务器；清除浏览器数据或更换设备后，记录不会自动同步。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库。
2. 将本目录内全部文件上传到仓库根目录。
3. 进入仓库 `Settings → Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 选择 `main` 分支和 `/ (root)` 目录并保存。
6. 等待约1—3分钟，GitHub 会显示公开访问地址。

本项目是纯静态网页，无需安装依赖或执行构建命令。

## 说明

- 词汇训练能够支持雅思备考，但不能单独预测或保证雅思6.5分。
- 浏览器发音由设备自带语音引擎提供，不同设备的音色可能不同。
- 1.0版采用本机存储，适合单个孩子在固定设备上连续试用一个月。
