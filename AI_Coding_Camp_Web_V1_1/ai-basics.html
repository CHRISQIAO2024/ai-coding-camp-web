AI Basics

AI 基础：从文字接龙开始

孩子不需要先学复杂数学，也可以先理解大语言模型的基本工作方式：看前文、猜下一个、再不断接下去。

课堂案例：你喜欢什么外语？

这是替代“你喜欢什么水果”的同类案例，既生活化，又能自然引出 Token 和预测。

输入

你喜欢什么外语？

模型先看到这句话，但它不会一次性吐出完整答案，而是一步一步预测。

预测

我

根据上下文，模型判断下一个很可能是“我”。

继续

喜欢

有了“你喜欢什么外语？我”，下一个高概率词变成“喜欢”。

结果

英语

继续接下去，就可能形成“我喜欢英语”。

变化

法语 / 日语 / 西班牙语

不同上下文、训练数据和随机性，会让模型给出不同答案。

重点

不是背答案

它更像是在大量语言经验中寻找最合适的下一个表达。

Token 是什么？

Token 是模型处理文字的基本单位。它不一定等于一个字，也不一定等于一个词，而是模型自己学到的切分方式。

Tokenizer 是什么？

Tokenizer 像中间人：把人类文字编码成数字，再把模型输出的数字解码回文字。

人类文字：你喜欢什么外语？
编码之后：[102, 450, 99, 801]
模型预测：[203]
解码结果：英语
